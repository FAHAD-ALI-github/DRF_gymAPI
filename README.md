## 📦 Deployment

This repository is maintained on GitHub so the latest source code can easily be cloned or downloaded whenever updates need to be deployed to the **PythonAnywhere** server.

---

## 🚀 Installation

```bash
git clone https://github.com/FAHAD-ALI-github/DRF_gymAPI.git

cd DRF_gymAPI

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
